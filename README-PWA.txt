DORENTO'S SYSTEM - PWA

This version is prepared for Android installation as a Progressive Web App.

A PWA normally needs HTTPS for the Install App option and service worker.
Upload these files to an HTTPS static host, then open the address on Android Chrome
and choose Chrome menu -> Add to home screen / Install app.

The current prototype stores data locally. Future versions can add cloud sync,
notifications, native camera integration, and richer progression.
